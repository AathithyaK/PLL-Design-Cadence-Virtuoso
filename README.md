# PLL-Design-Cadence-Virtuoso
# Energy-Efficient PLL-Based Clock Generator Using a Ring VCO

## Project Overview
This project focuses on designing and simulating a Phase-Locked Loop (PLL)-based clock generator using Cadence Virtuoso EDA tools in 180 nm CMOS technology.

## Key Blocks
- Phase-Frequency Detector (PFD)
- Charge Pump (CP)
- Third-Order Passive Loop Filter
- Ring Voltage-Controlled Oscillator (VCO)
- Frequency Divider

## Tools and Technology
- Cadence Virtuoso
- 180 nm CMOS technology

## Project Documentation
The project review presentation contains the design methodology, circuit implementation, simulation results, and future scope.

## Learning Outcomes
Gained practical exposure to transistor-level circuit design, simulation, and PLL operation.
